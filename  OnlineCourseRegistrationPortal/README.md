# College Event Management System

## Project Overview

The College Event Management System is a responsive web application developed using HTML5, CSS3, Bootstrap 5, and JavaScript. The system allows students to view upcoming events, register for events, check event schedules, browse event galleries, access FAQs, and contact event coordinators.

The application also uses Local Storage and Session Storage to manage event registrations and prevent duplicate registrations.

## Storage Functionality

### Local Storage

Stores registered student information permanently in the browser and prevents duplicate registration for the same event.

### Session Storage

Stores the current user's registration session and displays a welcome message when revisiting the registration page during the same browser session.
