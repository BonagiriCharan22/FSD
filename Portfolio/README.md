# Personal Portfolio Website

A responsive personal portfolio website developed using HTML, CSS, Bootstrap and JavaScript.

## Features

* Responsive Navigation Bar
* Home Section
* About Me Section
* Skills Section
* Projects Section
* Achievements Section
* Contact Form
* Bootstrap Modal
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
