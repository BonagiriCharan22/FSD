# Responsive Student Management Portal Using Bootstrap 5

## Project Overview

The Responsive Student Management Portal is a web-based application developed using HTML, CSS, Bootstrap 5, and JavaScript. The portal provides an intuitive and responsive interface for managing student-related information such as registration, profiles, dashboard statistics, attendance records, and contact details.

The application is fully responsive and adapts seamlessly across mobile, tablet, and desktop devices.
